# Task Talent Tapestry

**Task Talent Tapestry** is a dynamic web application designed to weave together effective task management with talent visualization. It provides a streamlined interface for organizing projects while highlighting the skills and contributions of team members.

**Live Demo:** [www.ownstore.org](www.ownstore.org)  
*(Note: If your live link is different, please update this URL)*

## 🚀 Project Overview

The goal of this project is to create a unified platform where project requirements meet human potential. Unlike standard to-do lists, Task Talent Tapestry focuses on assigning the right tasks to the right talent, creating a "tapestry" of productivity.

### Key Objectives
* **Simplify Workflow:** Intuitive drag-and-drop or list views for managing daily tasks.
* **Highlight Talent:** Profile views or tags that showcase user skills alongside their assigned tasks.
* **Visual Progress:** Clear indicators of project status and team workload.

## ✨ Features

* **Task Management:** Create, edit, delete, and categorize tasks efficiently.
* **Talent Dashboard:** View team members, their roles, and current availability.
* **Skill Tagging:** Assign specific skills (e.g., "Design", "Development") to tasks and users.
* **Responsive Interface:** Optimized for usage on both desktop and mobile devices.
* **Search & Filter:** Quickly find tasks by assignee, priority, or keyword.

## 🛠️ Technology Stack

This project is built using standard web technologies to ensure performance and compatibility:

* **HTML5:** Structure and semantic markup.
* **CSS3:** Custom styling, grid layouts, and responsive design.
* **JavaScript (ES6+):** Logic for task manipulation, DOM updates, and user interactivity.
* **FontAwesome:** For intuitive icons and UI elements.
